# PhoneBot — اپ کنترل گوشی (پروژه Android Studio)

این یک پروژه‌ی کامل اندروید استودیویی است. خودت آن را باز و Build می‌کنی و روی گوشی نصب می‌شود؛ بعد از نصب و دادن دو مجوز، دیگر به کامپیوتر نیازی نیست.

## ۱. ساخت APK
1. **Android Studio** را نصب کن (رایگان): https://developer.android.com/studio
2. پوشه‌ی `PhoneBotApp` (همین پوشه) را با Open باز کن. اولین بار که باز می‌شود، Android Studio خودش Gradle و SDK لازم را سینک می‌کند (چند دقیقه طول می‌کشد، اینترنت لازم دارد).
3. از منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. وقتی تمام شد، لینک «locate» را بزن یا برو به:
   `app/build/outputs/apk/debug/app-debug.apk`

## ۲. نصب روی گوشی
- فایل `app-debug.apk` را به گوشی بفرست (تلگرام به خودت، ایمیل، کابل، هر چی).
- روی فایل در گوشی بزن تا نصب شود. اگر اندروید جلویش را گرفت («منبع ناشناس»)، اجازه‌ی نصب از آن منبع را بده.
- بعد از نصب هم می‌شود مستقیم از Android Studio با دکمه‌ی ▶ Run روی گوشی وصل‌شده نصب کرد.

## ۳. راه‌اندازی داخل اپ (فقط یک‌بار)
اپ «PhoneBot» را باز کن:
1. دکمه‌ی **«فعال‌سازی دسترسی اعلان‌ها»** → در صفحه‌ی باز شده، PhoneBot را پیدا کن و روشن کن.
2. دکمه‌ی **«فعال‌سازی Accessibility»** → PhoneBot را در لیست سرویس‌های Accessibity پیدا و روشن کن (اندروید هشدار می‌دهد که این سرویس می‌تواند صفحه را ببیند و لمس کند — طبیعی و لازم است).
3. برگرد به اپ؛ وضعیت بالای صفحه باید «فعال ✅» نشان بدهد.

از این به بعد، همین روی خود گوشی و بدون کامپیوتر کار می‌کند.

## دستورها (در کادر متنی داخل اپ)
| دستور | کار |
|---|---|
| `notifs` | نمایش لاگ اعلان‌های ضبط‌شده |
| `ids` | نمایش آیدی/نام‌کاربری‌های استخراج‌شده |
| `screen` | متن فعلی روی صفحه |
| `shot` | اسکرین‌شات (در `Android/data/com.phonebot.app/files`) |
| `tap X Y` | لمس مختصات |
| `swipe x1 y1 x2 y2` | سوایپ |
| `scroll up\|down` | اسکرول |
| `key back\|home\|recents` | دکمه‌ها |
| `type متن` | تایپ در فیلد فعال (فارسی هم کار می‌کند) |
| `find متن` | زدن روی المانی که این متن را دارد |
| `open telegram\|whatsapp\|instagram\|chrome\|youtube\|messages\|پکیج` | باز کردن اپ |
| `url آدرس` | باز کردن لینک |
| `sms شماره متن` | ارسال پیامک |

آیدی‌ها و اعلان‌ها **خودکار و همیشه در پس‌زمینه** ضبط می‌شوند، حتی بدون باز کردن اپ — فقط باید مجوزهای بالا را یک‌بار داده باشی. دکمه‌ی «اشتراک آیدی‌ها» فایل `ids.txt` را برای ارسال (تلگرام/ایمیل و…) باز می‌کند.

## نکات
- این یک اپ شخصی و بدون امضای رسمی (debug build) است، فقط برای گوشی خودت.
- `tap`/`swipe`/`type`/`find` فقط وقتی کار می‌کنند که Accessibility فعال باشد.
- اگر گوشی سامسونگ/شیائومی و… باتری‌خور اپ را ببندد، از تنظیمات باتری، PhoneBot را «بدون محدودیت» کن تا سرویس اعلان‌ها قطع نشود.
- کد کامل در `app/src/main/java/com/phonebot/app/` است؛ هر تغییری خواستی همان‌جا اعمال کن و دوباره Build بگیر.
